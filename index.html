01 DIGITAL LIBRARY & REFERENCE

I Ching · 64 Hexagrams

A reading companion for the Book of Changes. Plain-text and illustrated editions, line-by-line commentary, and hexagram relationships, built from one structured source of truth.

  • Python
  • MkDocs Material
  • Web Workers
  • GitHub Actions
Inside the build

A single JSON source defines hexagram order, trigrams, and line polarity. Nuclear, inverse, reverse, and line-change relationships are computed at build time. Automated validation checks all six changed-hexagram references on every page.

Full-text search runs in a Web Worker, keeping queries in the browser. A generated character-folding table supports both Simplified and Traditional Chinese, while preserving distinctions in hexagram names.

02 EVENT-DRIVEN SYSTEMS

Discord Message Ingestion

An asynchronous service that backfills channel history and captures live events in SQLite. Built to handle delayed edits, out-of-order deletions, and connection gaps.

  • Python
  • asyncio
  • discord.py
  • aiosqlite
Inside the build

Message-ID upserts use a recency guard so stale backfill cannot overwrite newer edits. Tombstones preserve deletions that arrive before inserts. A forward-only cursor compares snowflakes by length before value, and background reconciliation closes gaps after disconnects.

Twenty tests exercise these cases against fake channels without a network or token. The bot requests only three required intents and keeps message content out of logs by default.
